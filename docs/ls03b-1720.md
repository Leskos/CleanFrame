# 2022 The Frame: LS03B on firmware 1720

Target for this fork: **QE55LS03BAUXXU** (2022 Frame, UK), firmware **1720**,
Tizen **6.5**, web engine Chromium **85**. This file records what has been checked
off the TV. No device result is claimed here; nothing has been installed yet.

## Source review against Chromium 85

Upstream 0.7.0 (`845f332`) was reviewed for this target on 2 November 2026.

| Area | Result |
| --- | --- |
| Installation floor | `app/config.xml` requires Tizen 5.0, which admits 6.5 without a manifest change. |
| JavaScript | ES5 grammar enforced by `eslint app`; no runtime API newer than Chromium 85 is used. `focus({ preventScroll })` is supported from Chromium 64. |
| CSS | The Chromium 85 `inset` and rounded-lens fixes are already upstream (`0063e6f`, tested on a QA75LS03BASXNZ). |
| `:focus-visible` | Chromium 86+, so Chromium 85 drops that one rule. Remote focus uses `.is-focus`, so TV navigation is unaffected; only desktop keyboard outlines are lost. |
| Source checks | `npm run check`: lint, static checks and 10 device-adapter tests pass. |
| Browser checks | `CLEANFRAME_PUBLIC_FONTS=1 npm run check:browser`: 421 checks pass, including the label-width and lens checks at 1920×1080 and 1280×720. |

The browser checks run current Playwright Chromium, not Chromium 85. They cover
layout and navigation regressions, not the TV compositor or remote feel.

## Fork changes

- **PS5 tile.** Home has a fixed PS5 entry for HDMI 4 (`INPUT_APPS` in
  `app/main.js`). OK requests that input through the same adapter as Settings →
  Samsung → Inputs. It is on the default Home and can be removed or re-added in
  the Home editor; it is not listed in All apps. Change `input` or `name` there
  if the console moves. Mark: Simple Icons PlayStation (CC0).
- **No Dock scrolling up to nine apps.** Full tiles narrow to fit the broad
  shelf: 288px for five, 276px for six, 235px for seven, 205px for eight and
  181px for nine. Labels step down (36 → 32 → 30px, or 40 → 34 → 30px in
  Text) only when a name no longer fits. Below `DOCK_MIN_TW` (180px) the
  scrolling dock returns; Home holds nine, so that applies only while
  arranging. Tiles are drawn live; only the glass behind the Dock is
  pre-rendered, as a full-screen image the Dock reveals at any width.
- **BBC iPlayer mark.** The installed app is recognised by its exact name,
  `BBC iPlayer`, because its app ID is not known for every region. Add it to
  Home once in the Home editor on the TV; the choice is saved. Mark: BBC blocks
  from Custom Brand Icons (MIT), with the full name as the label.
- **Brighton wallpapers.** Four Wikimedia Commons photos lead the gallery:
  West Pier sunset (the default for a fresh install), West Pier blue, West
  Pier sunrise and Palace Pier gold. They use the repo's centred-crop and
  material recipes; credits and CC BY / CC BY-SA terms are in
  [asset sources](asset-sources.md#brighton-photographs-this-fork). Their
  catalogue values were tuned with `check-gallery-contrast.mjs`: every rated
  label meets the 3:1 minimum in List and Dock with all three materials
  (lowest 3.45). Saved preferences keep their chosen wallpaper; only a fresh
  install starts on West Pier sunset.

Not yet seen on the TV: the PS5 picture after switching, CEC wake of a sleeping
console, and Home returning from the PS5. One 2020 Frame showed a no-signal screen
after a `tvwindow` switch ([frame-2020.md](frame-2020.md#hdmi-observations)).

## Native Home is out of scope

The reference helper targets .NET 6 and refuses other firmware. Tizen 6.5 TVs on
1720 ship .NET 3.1. No reversible route, including restore of an empty original
Home value, has been verified on an LS03B. Do not widen the reference guard;
treat any attempt as a separate experiment under
[the setup guide](agent-tv-setup-guide.md#prepare-recovery-before-any-native-write).

## Still to check on the TV

Follow [the staged setup guide](agent-tv-setup-guide.md) with your own Samsung
certificates and SDK-generated app identity.

- Record the full firmware string from About This TV, not only `1720`.
- Signed installation shows `install completed` and an installed-app entry.
- Dock and List render with labels and rounded focus; remote navigation works.
- Installed apps are discovered and launch; Samsung Home escape returns.
- Saved preferences survive an app restart and an in-place update.
- Settings → Samsung → Inputs lists HDMI sources and switches correctly.
- The PS5 tile shows the console on HDMI 4, wakes it if asleep, and Home returns.
- BBC iPlayer appears in the Home editor with its mark and launches from Home.

## Developing on Windows

The scripts call `python3`, which on Windows is usually a Store alias. The browser
checks now use `python` on Windows or `PYTHON` when set. For the `npm run`
scripts, put a real `python3` on `PATH`, for example a virtual environment with
`python.exe` copied to `python3.exe` in its `Scripts` folder. Node 22.13+ is required.
